# IELTS Atlas، نسخه‌ی فارسی و انگلیسی

این پوشه کپی برنامه‌ی [sallowayma-git/IELTS-practice](https://github.com/sallowayma-git/IELTS-practice) (نسخه‌ی اصلی و به‌روز) هست که **همه‌ی متن‌های چینی‌ش حذف شده**. فقط فارسی و انگلیسی مونده.
نسخه‌ی اصلی و دست‌نخورده کنارش تو `F:\Tool-Vault\sallowayma-git\IELTS-practice` هست.

## اجرا
- دابل‌کلیک روی `index.html`، با Chrome یا Edge.
- اگه بعضی بخش‌ها با دابل‌کلیک درست بارگذاری نشدن، تو همین پوشه این دستور رو بزن:
  `python -m http.server 8000`
  و بعد آدرس `http://localhost:8000` رو تو مرورگر باز کن.
- اولین بار که تمرین رو شروع می‌کنی، اجازه‌ی باز شدن پنجره‌ی جدید (popup) رو بده.

## چه تغییری کرده
| بخش | قبل | الان |
|---|---|---|
| منوها، دکمه‌ها، آمار، تنظیمات | چینی | فارسی |
| عنوان متن‌ها | انگلیسی + چینی | فقط انگلیسی |
| ترجمه‌ی چینی متن‌های ریدینگ | چینی | حذف شد |
| توضیح جواب‌ها (۲۸۸۰ سؤال) | توضیح کامل چینی | «سؤال n»، «جواب: …» و «جای جواب در متن» با جمله‌ی انگلیسی خود متن (جمله‌ی مرجع برای ۲۱۷۵ سؤال، و برای خیلی از بقیه شماره‌ی پاراگراف) |
| اسم انواع سؤال | چینی | فارسی (مثلاً تطبیق عنوان پاراگراف) یا True / False / Not Given |
| معنی لغت‌ها (دیکشنری و لیست لغات آیلتس) | چینی | تعریف انگلیسی از دیکشنری ECDICT/WordNet |

خود متن‌ها و سؤال‌های آیلتس انگلیسی‌ان و دست نخوردن.

**چیزی که از دست رفت:** استدلال چینی توضیح‌ها، که می‌گفت چرا یه جواب درسته. جواب درست و جمله‌ای که جواب ازش میاد هنوز هست. اگه یه روز توضیح فارسی کامل خواستی، می‌شه دسته‌دسته ترجمه‌شون کرد (از روی نسخه‌ی اصلی).

## چطوری ساخته شده
1. **`fa-tools/strip_cn.py`:** یه بار روی فایل‌های داده اجرا شده و متن‌های چینی رو حذف یا با انگلیسی جایگزین کرده. اسم فایل‌ها و مسیرهای داخلی دست نخورده، چون برنامه برای پیدا کردن PDFها بهشون نیاز داره.
2. **`js/i18n-fa.js`:** رابط کاربری رو موقع باز شدن صفحه فارسی می‌کنه. اگه به متن چینی‌ای برسه که ترجمه‌ش رو نداره، چینی‌ش رو حذف می‌کنه و تو `window.__ieltsFa.missing()` ثبتش می‌کنه، تا بعداً ترجمه‌ش اضافه بشه (بخش `EXACT`).
3. خط `<script>` مربوط به `i18n-fa.js` به چهار صفحه اضافه شده: `index.html`، `assets/generated/reading-exams/reading-practice-unified.html`، و دو فایل داخل `templates/`.

## به‌روزرسانی از نسخه‌ی اصلی
1. تو پوشه‌ی `ielts-practice` دستور `git pull` رو بزن.
2. یه کپی تازه بساز.
3. `js/i18n-fa.js`، `fa-tools/` و خط‌های `<script>` رو برگردون.
4. `python -I fa-tools/strip_cn.py <مسیر کپی>` رو اجرا کن.

یا از Claude بخواه این کار رو برات انجام بده.
