# هِسته — افزونهٔ تب جدید (New Tab)

تب جدید مرورگر را به یک نگاهِ سبک به امروزت تبدیل می‌کند:

- تاریخ **شمسی + قمری + میلادی** و سلامِ هوشمند بر اساس ساعت تهران
- **۳ کار بعدی** (با تیک «انجام شد»)
- **ثبت سریع**: چیپ‌های حال 😞…🤩، دکمهٔ «+۱ لیوان آب» 💧 و یک ورودی یک‌خطی (همان موتور `‎/api/ai/process` — متن آزاد، پیامک و کپی اپ بانکی)
- **آب‌وهوای شهر انتخابی خودت** (همان شهری که در هِسته ذخیره کرده‌ای)
- **خلاصهٔ دیروز**: کارهای انجام‌شده، جمع خرج، حال ثبت‌شده

## نصب (۲ دقیقه، بدون Web Store)

۱. در کروم برو به `chrome://extensions` و گوشهٔ بالا **Developer mode** را روشن کن.
۲. **Load unpacked** را بزن و همین پوشه (`newtab-extension/`) را انتخاب کن.
۳. یک تب جدید باز کن. اگر لاگین نبودی، اول در یک تب معمولی وارد هِسته شو
   (`https://pdmaz.hamidreza-mazlaghani.workers.dev`) — بعد تب‌های جدید خودشان وصل‌اند.

## اگر سلف‌هست کردی (سرور خودت)

آدرس اپ داخل `newtab.html` (متغیر `APP`) را به آدرس خودت عوض کن، مثلاً:

```js
var APP = 'http://localhost:3000/newtab.html';
```

بعد در `chrome://extensions` روی افزونه **⟳ Reload** بزن.

## معماری (چرا iframe؟)

صفحهٔ واقعی فقط در یک‌جا زندگی می‌کند: `public/newtab.html` (سورس واحد، دیپلوی‌شده روی
همان اپ). این افزونه فقط یک پوستهٔ ~۱KB است که همان صفحه را در iframe تمام‌صفحه لود می‌کند.
نتیجه:

- **بدون CORS و بدون دردسر کوکی**: داخل iframe همه‌چیز same-origin است.
- **همیشه تازه**: هر دیپلوی هِسته، تب جدید را هم به‌روز می‌کند — بدون آپدیت افزونه.
- **آفلاین**: اگر سرور در دسترس نباشد، به‌جای صفحهٔ سفید یک پیام روشن با دکمهٔ تلاش می‌بینی؛
  خودِ صفحه هم آخرین وضعیت (کارها/آب‌وهوا/خلاصهٔ دیروز) را کش می‌کند.
